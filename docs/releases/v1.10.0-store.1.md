Seaglass Store Edition on Seaglass 1.10.0: the controller fixes, the mouse wheel in big picture and the audit fixes from [Seaglass 1.10.0](https://github.com/ApolloF/Seaglass/releases/tag/v1.10.0), plus fixes to the store.

**From Seaglass 1.10.0**

- **The controller could stop being detected** and stay that way until Seaglass restarted. It now always ends up in the mode it was asked for, a controller layer that can't start tries again, and the controller is back as soon as a game ends.
- **The mouse wheel works in big picture**, moving the selection like the D-pad.
- A damaged settings file falls back to the copy from the last good start, two quick settings changes no longer undo each other, Epic and GOG sign-ins survive a refresh without a new token, and more fixes; the library search is faster.

**The store** (*Settings → Experimental → Store*)

- **Work cut short by closing Seaglass picks up again.** A safety scan that was running starts over, and an install that was running shows as failed with *Retry*, instead of both staying stuck.
- **Retrying an install works.** A retry no longer refuses the folder because of the files the first attempt left there.
- **Uninstalling never deletes another game's files.** When a game was installed into your games folder, a library folder, or a folder that holds another installed game, Seaglass runs its uninstaller (or says it can't remove it) and leaves the folder alone.
- *Download anyway* on a release the safety check held back no longer changes the original report.
- qBittorrent is stopped when Seaglass can't apply its network settings, so it doesn't keep running unconfigured.
- The Store page counts results once you stop typing instead of on every key.

This is experimental: expect rough edges.
