**Fixes**

- **Seaglass now says when Windows is slow to answer your controller.** A controller can get stuck in a state where every question Windows asks it waits for a timeout. Seaglass then finds it 25 seconds to a minute late, after starting and after every game, or seems not to find it at all. Reconnecting the controller ends it. When this happens, Seaglass shows a note telling you to unplug the controller and plug it back in. The log records how long each step took, and the diagnostics report flags it.
