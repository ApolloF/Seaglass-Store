**Fixes**

This release changes how Seaglass is tested, not how the app behaves. It goes with Syncer 0.15.0, which brings back a Seaglass data folder that was emptied.

- The end-to-end test harness no longer deletes `%APPDATA%\Seaglass` before restoring its backup. If the backup is missing or incomplete, it leaves your library, settings and playtime alone. If a copy fails, it puts the current folder back. When it restores a backup an earlier run left behind, it keeps the current folder next to it.
- Tests no longer write to the real `seaglass.log`.
- A test checks that a restored copy of this PC's profile file (which Syncer writes next to a file made again) adds up with it: playtime is summed, achievements are combined.
