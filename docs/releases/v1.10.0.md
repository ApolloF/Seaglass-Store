**New**

- **The mouse wheel works in big picture.** It moves the selection like the D-pad: one notch is one step, Shift or a sideways wheel goes left and right, and a touchpad's small scrolls add up to a step.

**Fixes**

- **The controller could stop being detected.** When a game ended while the next one started (or a game noticed outside Seaglass started just then), the controller layer could stay released for good, so big picture showed no controller until Seaglass restarted. It now always ends up in the mode it was asked for last. If the controller layer can't start, it tries again instead of staying off.
- **The controller comes back right after a game.** It used to wait for the save backup after the game, which can take minutes.
- **A controller Seaglass can't open is logged.** This usually means another program holds it for itself (HidHide, DS4Windows, DSX). The diagnostics report now shows the controller layer's mode.
- Two quick settings changes no longer undo each other.
- A damaged settings file (for example after a power cut) no longer resets your folders and settings: the copy from the last good start is used, and the damaged file is kept aside.
- The welcome keeps working with the controller. It used to switch to big picture underneath itself.
- Opening a screen from Quick access closes the game page that covered it.
- The overlay keeps the controller's battery up to date.
- Epic and GOG sign-ins survive a refresh that returns no new token.
- Play tracking finds a game process that couldn't be read the moment it started.
- Big picture Settings and Library tabs keep working when a list gets shorter. Closing a dialog with Esc or ○ keeps the focus where it was. Syncer calls recover after a write is cut short.

**Faster**

- Typing in the library search doesn't sort the whole library again for every key, and big picture search normalises each title once.
- Following a game's processes uses much less memory.
