Seaglass Store Edition on Seaglass 1.10.0: updates move to a new home, and the store starts with no sources on a new setup.

**Updates**

- **Updates now come from [Seaglass-Store-Releases](https://github.com/ApolloF/Seaglass-Store-Releases).** Nothing to do: this version switches over by itself. Every update is still checked against the same release signature before it installs.
- **A failed update check says so.** When the update server can't be reached, *Settings → About* shows an error instead of "up to date".
- *Download* and *Report a problem* in *Settings → About* open the new releases page.

**The store** (*Settings → Experimental → Store*)

- **New setups start with no sources.** Turning the Store on for the first time no longer turns any source or *Browse release sources* on, so nothing is indexed until you choose sources in Store settings. If you already use the Store, your sources and settings stay as they are.
- Wording updates.

This is experimental: expect rough edges.
